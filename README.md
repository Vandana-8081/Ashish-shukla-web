# Ashish Shukla - Official Profile Website

A premium, modern, editorial-style Indian public-profile website for **Ashish Shukla** (166-Bhagwant Nagar, Unnao).

## Key Features & Highlights

- **Tech Stack**: Next.js (App Router), TypeScript, Tailwind CSS, Lucide Icons, Framer Motion.
- **Design Philosophy**: Dignified, grounded, editorial Indian aesthetic. Large serif typography, cream/warm-white backgrounds (`#F8F4ED`), saffron accents (`#F5660A`), dark footer (`#151210`), and strict zero-pill discipline.
- **Bilingual Support**: Seamless Hindi (हिन्दी) and English (EN) language toggling across all sections and data models.
- **Actual Photographic Assets**: Real photographs in `/public/images/` for hero slides, portraits, journey timeline, public life & Jan Sunwai hearings, rural health centers, link roads, and news updates.
- **Structured Sections**:
  - **Hero Slider**: Editorial headings, authentic photography, clear calls to action.
  - **Biography & Roots**: Formative rural values, entrepreneurship in Kanpur/Lucknow, returning home to service.
  - **Life Journey**: Chronological milestones (Early Years, Professional Journey, Return to Bhagwant Nagar, Public Life).
  - **Public Life & Jan Sunwai**: Dedicated grievance redressal forums, transparent governance, village chaupals.
  - **Development Priorities**: Community health centers, rural link roads, education, farmers, youth livelihood, women SHGs.
  - **Bhagwant Nagar**: Cultural heritage and grassroots commitment.
  - **Latest Updates & Dynamic Pages**: Filterable updates grid and dedicated slug-based article pages (`/updates/[slug]`).
  - **Media & Gallery**: Curated photo gallery and featured video players.
  - **Social Section & Sticky Nav**: Authentic official social channels (Facebook, Instagram, X).
  - **SEO & Structured Data**: OpenGraph cards, Twitter cards, sitemap.xml, robots.txt, and Schema.org JSON-LD structured data.

## Getting Started

```bash
# Install dependencies
npm install

# Start development server on port 3000
npm run dev

# Build for production
npm run build
```
